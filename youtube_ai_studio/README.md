# YouTube AI Studio

Turn a single topic into a complete **faceless-channel video** — script, voiceover,
visuals, a stitched MP4, a thumbnail, and publish-ready metadata — from a desktop
GUI.

It pairs with the existing *Simple YouTube to MP3 Downloader* in this repo: that
tool pulls audio *down* from YouTube; this one helps you produce content to put *up*.

## Pipeline

```
Topic ─▶ Script + metadata (Claude)
      ─▶ Voiceover per scene (gTTS / pyttsx3)
      ─▶ Visual card per scene (Pillow)
      ─▶ Stitch image+audio clips → final MP4 (ffmpeg)
      ─▶ thumbnail.png + metadata.json + transcript.txt
```

The script and all publish metadata (title, description, tags, thumbnail text)
are generated by **Claude (`claude-opus-4-8`)** using structured outputs, so the
response is always a valid, parseable plan.

## Setup

1. **Python deps**

   ```bash
   pip install -r youtube_ai_studio/requirements.txt
   ```

2. **ffmpeg** (system dependency, includes `ffprobe`)

   - macOS: `brew install ffmpeg`
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - Windows: download a build and add its `bin/` to your `PATH`

3. **Anthropic API key**

   ```bash
   export ANTHROPIC_API_KEY="sk-ant-..."
   ```

   (or paste it into the app's *API key* field)

## Run

```bash
python -m youtube_ai_studio.app
```

Enter a topic, pick a style / format / voice, and click **Generate Video**.
Output lands in `output/<topic-slug>/`:

| File | What it is |
|------|------------|
| `video.mp4` | the finished video |
| `thumbnail.png` | generated thumbnail |
| `metadata.json` | title, description, tags, thumbnail text |
| `transcript.txt` | full narration script |
| `assets/` | per-scene images, audio, and clips |

## Formats

- **landscape** — 1920×1080 standard YouTube video
- **short** — 1080×1920 vertical (Shorts / Reels / TikTok)

## Notes & extension points

- **Visuals** are clean generated title cards (no paid image API needed). To use a
  real image-generation service, swap `pipeline/image_generator.render_scene_image`
  to download a generated image and composite the caption onto it.
- **Voice**: gTTS (natural, needs internet) is preferred; install `pyttsx3` for a
  fully offline fallback.
- **Uploading**: this tool produces the files; it does not auto-upload. Add a
  `pipeline/uploader.py` using the YouTube Data API if you want one-click publish.
